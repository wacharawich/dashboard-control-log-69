# ราคาเสนอ · Terminal Dashboard — เวอร์ชัน Google Apps Script

ไฟล์ชุดนี้ใช้สำหรับสร้าง **Web App** บน Google Apps Script โดยไม่ต้องมี server ใดๆ
— อ่านข้อมูลสดจาก Google Sheet ทุกครั้งที่เปิดหน้า และรองรับการกรอง 9 มิติ
(เลือกได้หลายค่า) + ช่วงเวลา, กราฟ, ตาราง, **แก้สถานะกลับลงชีต** และ Export CSV / PDF

## ไฟล์

| ไฟล์       | หน้าที่                                                            |
| ---------- | ------------------------------------------------------------------ |
| `code.gs`  | backend — `doGet()` เสิร์ฟหน้าเว็บ, `getSheetData()` อ่านชีต A–K, `updateStatus()`/`doPost()` เขียนสถานะลงคอลัมน์ K |
| `index.html` | frontend ทั้งหมดในไฟล์เดียว (ธีม terminal light, ไม่พึ่ง CDN ภายนอก) |

## วิธีติดตั้ง (ครั้งแรก ~3 นาที)

1. เปิด https://script.google.com → **New project** (หรือเปิดโปรเจกต์เดิม)
2. เปิดไฟล์ **Code.gs** → ลบเนื้อหาเดิม → วางโค้ดจาก `code.gs` ทั้งหมด
   - ถ้า Spreadsheet ไม่ใช่ของบัญชีเดียวกันกับที่ deploy ต้องไปกด **Share** ชีตให้บัญชีนี้ก่อน (อ่านได้อย่างเดียวก็พอ)
3. ไปที่ **ไฟล์ (Files) > +** → **HTML** → ตั้งชื่อไฟล์ว่า **`index`** (ตัวพิมพ์เล็ก — ห้ามตั้งชื่ออื่น เพราะ `code.gs` เรียก `createHtmlOutputFromFile("index")`)
   → ลบเนื้อหาเดิม → วางโค้ดจาก `index.html` ทั้งหมด
4. กด **Deploy > New deployment** → เลือกชนิด **Web app**
   - **Execute as** : `Me` (บัญชีที่ deploy)
   - **Who has access** : `Anyone` (หรือ `Anyone with Google account` ถ้าต้องการจำกัด)
5. กด **Deploy** → กดอนุญาตสิทธิ์ตามที่ขอ (ต้องอ่าน Spreadsheet) → คัดลอก **Web app URL** ที่ได้
6. เปิด URL นั้น — ข้อมูลจะโหลดจากชีตอัตโนมัติ (ข้อมูล ~8,000 แถว อาจใช้เวลา 2–5 วินาทีในครั้งแรก)

> เวลาแก้ไขโค้ด: แก้เสร็จแล้วกด **Deploy > Manage deployments > ✎ (edit) > Version: New version > Deploy**
> เพื่อเผยแพร่เวอร์ชันใหม่ (URL เดิมยังใช้ได้)

## เชื่อมต่อกับเว็บแอปหลัก (React/Convex)

หน้าเว็บหลัก (dashboard React) มีปุ่มแก้สถานะด้วย — เว็บแอปหลักจะส่ง `POST` มา Web App
ตัวนี้ด้วย JSON `{ "regNo": "เลขทะเบียนคุม", "status": "อนุมัติ" }` ผ่านฟังก์ชัน `doPost()`
ใน `code.gs` เพื่อเขียนสถานะลงชีต

วิธีเชื่อมต่อ:
1. Deploy Web App ตัวนี้ตามขั้นตอนด้านบน (ต้องเลือก **Who has access: Anyone** เพื่อให้ POST จากภายนอกเข้าได้)
2. คัดลอก **Web app URL**
3. เปิดโปรเจกต์หลักใน Freebuff → ไปที่หน้า **Keys/API keys** → เพิ่มคีย์ชื่อ **`APPS_SCRIPT_WEB_APP_URL`**
   วาง URL ที่คัดลอกมาเป็นค่า
4. เปิด dashboard อีกครั้ง — เลือกสถานะในตารางแล้วข้อมูลใน Google Sheet จะเปลี่ยนตาม

## ฟีเจอร์

- **ตัวกรอง 9 มิติ** เลือกได้หลายค่า: เลขทะเบียนคุม · เดือน · กลุ่มภารกิจ · กลุ่มงาน · หน่วยงาน · รายการ · หมวด · ประเภท · ประเภทแผน
  - OR ภายในมิติเดียวกัน, AND ข้ามมิติ — ตัวเลือกของแต่ละมิติอัปเดตตามชุดข้อมูลที่ถูกกรอง
  - เลือกแล้ว **กราฟ / KPI / ตาราง รีเฟรชทันที** ไม่ต้องกดปุ่ม
- **ตัวกรองช่วงเวลา [DAT]**: เลือกวันที่เริ่มต้น/สิ้นสุด (จาก–ถึง) เพื่อกรองตามคอลัมน์ เดือน
  - รองรับทั้งค่าแบบเต็มวัน "19 ก.ย. 2025" และแบบเดือน "ก.ย. 2025" ในชีต
  - ใช้ร่วมกับตัวกรองมิติอื่นได้ — ตัวเลือกของมิติอื่นจะอัปเดตตามช่วงเวลาที่เลือก และแสดงเป็น chip `DAT` ให้ลบได้
- **KPI**: ยอดรวมราคาเสนอ · จำนวนรายการ · จำนวนหน่วยงาน · ค่าเฉลี่ยต่อรายการ
- **กราฟ**: ยอดรวมราคาเสนอจำแนกตามมิติใดก็ได้ (สลับได้) · สัดส่วนตามหมวด (donut) · TOP 10 หน่วยงาน · สถิติแยกตามประเภทแผน (ในแผน/นอกแผน/ทดแทน)
- **ตารางข้อมูล**: 11 คอลัมน์ (รวม **สถานะ** คอลัมน์ K), เรียงลำดับได้ (เลขทะเบียนคุมเรียงแบบตัวเลข, เดือนเรียงตามเวลา), แบ่งหน้า 12 แถว
  - **แก้สถานะจากตารางได้**: คอลัมน์ สถานะ เป็น Dropdown (เสนอ / อนุมัติ / ไม่อนุมัติ / รอปรับแผน) — เลือกแล้วเขียนกลับลงชีต
    ทันทีผ่าน `google.script.run.updateStatus()` (หาแถวจากเลขทะเบียนคุม คอลัมน์ A แล้วเขียนคอลัมน์ K)
- **Export CSV**: ข้อมูลที่ถูกกรองทั้งหมด (รวมคอลัมน์สถานะ), มี BOM ให้ Excel อ่านภาษาไทยได้ถูกต้อง
- **Export PDF**: เปิดหน้าต่างพิมพ์ → เลือก **"Save as PDF"** → ได้ไฟล์ PDF **A4 แนวนอน** พร้อมหัวรายงาน + สรุป + ตัวกรอง (รวมช่วงเวลา `DAT`) + ตาราง (สูงสุด 500 แถว, เรียงตามเลขทะเบียนคุมน้อยไปมาก, ข้อความยาวขึ้นบรรทัดใหม่ไม่ตัดคำ)

## หมายเหตุทางเทคนิค

- **ทำไมไม่มี Chart.js/jsPDF ผ่าน CDN?** HtmlService ใช้ sandbox `IFRAME` ที่มี Content Security Policy
  **บล็อกสคริปต์จาก CDN ภายนอก** (เช่น jsdelivr/cdnjs) ไฟล์นี้จึงวาดกราฟด้วย CSS บริสุทธิ์
  (แท่ง CSS + donut `conic-gradient`) และใช้ `window.print()` สำหรับ PDF — รับประกันว่าวางแล้วรันได้จริง
- Google Fonts (Prompt + JetBrains Mono) อนุญาตให้โหลดได้ใน Apps Script
- ถ้าอยากแก้ Spreadsheet/ชื่อชีต: เปลี่ยนค่าคงที่ `SHEET_ID` / `SHEET_NAME` ด้านบนของ `code.gs`
- ถ้าข้อมูลเกิน ~10,000 แถว หน้าแรกอาจโหลดช้า แนะนำให้จำกัดข้อมูลในชีต หรือใช้ Query ของ Google Sheets (gviz) แทน
